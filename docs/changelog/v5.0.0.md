## Executive Summary

TechyMind **v5.0.0** represents a comprehensive unification of all architectural milestones, UI redesigns, local model capabilities, and privacy engines into a singular, production-hardened release.

This version incorporates the **Google Stitch 60-30-10 Crimson Editorial Design System**, primary on-device **Google Gemma 3** integration via Ollama, a fully populated **12-Skill Procedural Library**, fail-closed **On-Device Privacy Firewall**, and an interactive judge evaluation testbed.

## 2. On-Device Privacy Firewall (Fail-Closed Architecture)

TechyMind operates on a strict **zero-raw-pixel / zero-raw-token** guarantee before any representation leaves the user's device:

1. **Biometric Face Masking**:
   - Integrated **MediaPipe** on-device face detector.
   - Applies dual-layer protection: Gaussian blur on facial coordinates plus an opaque black privacy eye-bar tape overlay.
2. **Deterministic DOM & Text Regex Engine**:
   - Indian national identifiers: Strict 12-digit **Aadhaar** masking (`[REDACTED: AADHAAR]`) and alphanumeric **PAN** (`[REDACTED: PAN]`).
   - Financial credentials: Luhn-validated **Credit Card** numbers and CVVs turned into solid-black privacy redactions.
   - Authentication secrets: High-entropy **API keys**, passwords, and **2FA OTP** tokens masked in browser memory.
   - Contact details: Soft pixelation/blur applied to emails and phone numbers.
3. **Canvas Redactor & Fail-Closed Gate**:
   - If any detector fails or memory bounds are exceeded, outbound transmissions default to fail-closed state.

## 4. Complete 12-Skill Procedural Library

The bundled skill suite in `skills/` operates with folder-based YAML frontmatter and strict step-by-step procedures:

1. **Fill Form (`fill-form`)**: Safe form completion using user profile data without submitting without explicit permission.
2. **Summarize Page (`summarize-page`)**: Zero-navigation readable page summarization with concise bullets and TL;DR.
3. **Deep Research (`deep-research`)**: Multi-source investigation across 3+ independent sources with URL citations.
4. **Extract Data (`extract-data`)**: Scraping repeating tables and rows into structured JSON/CSV datasets.
5. **Compare Prices (`compare-prices`)**: Cross-store price checking across Amazon, Flipkart, etc.
6. **Find Alternatives (`find-alternatives`)**: Discovery and vetting of replacement software and tools.
7. **Manage Bookmarks (`manage-bookmarks`)**: Audit, deduplication, and topic grouping of browser bookmarks.
8. **Monitor Page (`monitor-page`)**: Change detection and numeric diffs on dynamic pages.
9. **Organize Tabs (`organize-tabs`)**: Multi-window tab management and duplicate tab pruning.
10. **Read Later (`read-later`)**: Distraction-free article extraction and reading queue management.
11. **Save Page (`save-page`)**: Complete DOM archiving and markdown bundling.
12. **Screenshot Walkthrough (`screenshot-walkthrough`)**: Step-by-step annotated visual guides.

All skills are inspectable, hot-editable, and customizable directly within the Settings webpage.

## 6. Execution Safety & Task Authorization Daemon

- **Task Authorization Daemon**:
  - Purchase, deletion, and financial actions require explicit authorization present in the user's initial prompt text.
  - Negation-order parsing (e.g. *"do not buy"*, *"cancel instead"*) strictly enforced.
- **Element Disambiguation Receipts**:
  - Numbered disambiguation badges and receipt paths (`"Buy Now #2"`) resolve identical multi-button ambiguous targets.
- **Streaming Failure Ladder**:
  - 45s idle watchdog with automatic thinking-off fallback and non-stream recovery.
